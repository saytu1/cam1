# 프로젝트 요청사항 관리

이 파일은 사용자 요청사항과 반영 상태를 기록합니다. 새 요청이 생기면 아래에 추가합니다.

## 요청 이력

### 2026-11-08 — 최초 요청
| # | 요청 내용 | 반영 상태 | 비고 |
|---|-----------|-----------|------|
| 1 | 안드로이드에서 USB 카메라(UVC)로 동작하는 블랙박스 앱 APK | ✅ 반영 | UVCAndroid 1.0.13 라이브러리 사용 |
| 2 | 사용 목적: 홈캠 (상시 녹화) | ✅ 반영 | 포그라운드 서비스, 부팅 시 자동 시작, 카메라 분리/재연결 자동 복구, 워치독 |
| 3 | 32GB로 2일(48시간) 저장 가능 | ✅ 반영 | 기본값 720p / 15fps / 영상 1000kbps + 음성 32kbps ≈ 하루 11.1GB → 32GB(실사용 약 29GB)에 약 2.6일 |
| 4 | 저장 위치: SD카드 또는 내장공간 선택 | ✅ 반영 | 설정 > 저장 위치. SD카드 미장착 시 내장으로 자동 대체 |
| 5 | 오디오 포함 녹화 | ✅ 반영 | AAC 32kbps, 16kHz 모노 (설정에서 끄기 가능) |
| 6 | 빌드 방식: GitHub Actions | ✅ 반영 | `.github/workflows/build-apk.yml`, 결과 APK는 Actions 아티팩트 |

## 기본 녹화 설정 / 용량 계산
- 해상도 1280x720, 15fps, H.264 1000kbps, AAC 32kbps
- 초당 약 133KB → 시간당 약 0.46GB → 하루 약 11.1GB
- 32GB 카드: 약 62시간(2.6일) 보관 / 루프 녹화로 가장 오래된 파일부터 자동 삭제
- 1200kbps로 올려도 약 52시간(2.2일) 보관 가능

## 향후 개선 후보 (미반영)
- 영상에 날짜/시간 워터마크(OSD) 표시
- 움직임 감지 시에만 녹화 / 이벤트 파일 보호(삭제 방지)
- 원격 보기(웹/RTSP 스트리밍)
