# USB 홈캠 블랙박스 (Android)

안드로이드 기기에 **USB(UVC) 웹캠**을 연결해서 홈캠/블랙박스처럼 **24시간 루프 녹화**하는 앱입니다.

## 주요 기능
- USB 카메라(UVC) 자동 인식 · 연결 / 분리 후 재연결 시 자동 복구
- **날짜/시간 표시**: 녹화 영상 좌측 상단에 `YYYY-MM-DD HH:MM:SS` 새김 (설정에서 끄기 가능)
- N분 단위(기본 5분, 정각 기준) MP4 분할 녹화 (H.264 + AAC 음성), 파일 사이 녹화 공백 없음
- **루프 녹화**: 저장 공간이 부족하거나 설정한 최대 용량을 넘으면 가장 오래된 파일부터 자동 삭제
- **저장 폴더 선택**: 내장 저장소 / SD카드의 원하는 폴더 선택 또는 새 폴더 만들기 (기본 `Movies/BlackBox`)
- **예약 녹화**: 요일 + 시간대(여러 개, 자정 넘김 가능)를 정해 자동으로 녹화 시작/종료, 매주 반복
- **삭제 잠금**: 파일별 / 날짜별 잠금 → 전체 삭제·자동 삭제에서 보호, 잠금 파일만 모아 보기
- **전체 삭제**: 잠긴 파일을 제외하고 한 번에 삭제
- 백그라운드 녹화(포그라운드 서비스 + WakeLock), 부팅 시 자동 녹화 재개
- 녹화 목록에서 재생/삭제, 실시간 미리보기, 예상 보관 시간 표시
- 영상 정지(신호 없음) 감지 워치독 → 카메라 자동 재시작

## 32GB / 2일 저장
기본 설정(720p, 15fps, 영상 1000kbps + 음성 32kbps)은 하루 약 **11.1GB**를 사용합니다.
32GB 카드(실사용 약 29GB)에서 약 **62시간(2.6일)** 보관되므로 요구사항(2일)을 충족합니다.
화질을 더 원하면 설정에서 1200kbps(약 2.2일)까지 올려도 2일 보관이 가능합니다.

## 사용 방법
1. 앱 실행 → 카메라 / 마이크 / 알림 권한 허용
   (Android 9+ 에서는 USB 카메라 접근에도 **카메라 권한**이 필요합니다)
2. USB 카메라 연결 (OTG 젠더 필요) → USB 권한 팝업에서 **"항상 이 앱 사용"** 체크 후 허용
3. 자동으로 녹화 시작 (설정에서 끌 수 있음)
4. **설정 > 배터리 최적화 제외**를 꼭 눌러 주세요 (장시간 녹화 안정성)

## 저장 경로
- 기본: `내장 저장소/Movies/BlackBox/` (갤러리·파일 앱에서 바로 확인 가능)
- 설정 > 저장 폴더에서 내장/SD카드의 원하는 폴더 선택 또는 새 폴더 생성
- 원하는 폴더에 저장하려면 **'모든 파일 액세스' 권한**이 필요합니다(최초 실행 시 안내).
  권한이 없거나 폴더에 쓸 수 없으면 앱 전용 폴더(`Android/data/com.homecam.blackbox/files/BlackBox/`)에 저장되며,
  이 폴더는 앱 삭제 시 함께 삭제됩니다.
- 파일명: `BB_YYYYMMDD_HHMMSS.mp4`

## 예약 녹화
1. 설정 > 예약 녹화 설정 → '예약 녹화 사용' 켜기
2. '+ 예약 추가'로 요일(매일/평일/주말 빠른 선택)과 시작·종료 시각 지정
3. 예약 시간 외에는 카메라를 끄고 대기, 시간이 되면 자동으로 녹화 시작 (알림에 다음 녹화 시각 표시)

## 삭제 잠금
- 녹화 목록에서 파일을 **길게 누르기** → 파일 잠금/해제, 그 날짜 전체 잠금/해제
- **날짜 제목**을 누르기 → 날짜 잠금/해제, 그 날짜 파일 삭제
- 상단 **🔒 잠금** 탭: 잠긴 파일만 보기
- 잠긴 파일은 전체 삭제와 저장 공간 부족 시 자동 삭제에서 모두 제외됩니다.

## 참고 / 제한
- Android 14+ 에서 부팅 직후 자동 시작된 경우 시스템 정책상 마이크가 막힐 수 있습니다.
  이때는 앱을 한 번 열면 음성 녹음이 다시 활성화됩니다(영상은 계속 녹화).
- 음성은 기기의 기본 마이크(캠코더 소스)로 녹음됩니다.
- 기기에 따라 USB 전원 공급이 부족하면 카메라가 끊길 수 있으니 전원 공급형 OTG 허브를 권장합니다.
